# Portfolio images

Place project images and other static media in this folder. Reference them in Astro with paths such as:

```astro
<img src="/images/project-one.jpg" alt="Description of project one" />
```

Suggested files:

- `logo.svg` — your logo, used from `/images/logo.svg`
- `project-one.jpg`, `project-two.jpg`, etc. — project imagery
- `og-image.jpg` — social sharing preview image
